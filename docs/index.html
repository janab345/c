Exact-Width Types & Endianness

Why platform-agnostic integer types and byte-order awareness are non-negotiable in flight software.

Fixed-Width Integer Types (<stdint.h>)

The C standard only guarantees minimum ranges for built-in types. On a 32-bit CPU int is 32 bits; on a 16-bit CPU it may be 16 bits. Flight software targets multiple processors (SPARC, PowerPC, ARM, x86) — using unsigned int in a packet header means different byte sizes on different targets. NASA mandates fixed-width types throughout cFS.

IMPORTANT
Always use uint8_t, uint16_t, uint32_t, uint64_t, int8_t, int16_t, int32_t, int64_t for any value whose width matters. Include <stdint.h> (or <inttypes.h> for printf macros like PRId32).

Endianness

Endianness describes how multi-byte integers are stored in memory. Little-endian (x86, ARM default) stores the least-significant byte first. Big-endian (SPARC, PowerPC, network byte order) stores the most-significant byte first.

NOTE
CCSDS Space Packet Protocol mandates big-endian (network byte order) for all header fields. When building packets on a little-endian host, you must byte-swap every multi-byte field before writing it to the wire buffer.

The POSIX functions htons() (host-to-network short, 16-bit) and htonl() (host-to-network long, 32-bit) in <arpa/inet.h> perform this swap on little-endian hosts and are no-ops on big-endian hosts. For embedded targets without POSIX, write your own using bitwise operations.

TIP
Detect endianness at runtime by writing 0x01020304 into a uint32_t and reading the first byte as a uint8_t. If it reads 0x04, you are on a little-endian machine.

Runtime endianness detection 
/* ex2_endian.c — compile: gcc -std=c99 -Wall ex2_endian.c -o ex2_endian */
#include <stdint.h>
#include <stdbool.h>
#include <stdio.h>
#include <string.h>

typedef enum {
    ENDIAN_LITTLE = 0,
    ENDIAN_BIG    = 1,
    ENDIAN_UNKNOWN
} Endianness_t;

/* Detect host endianness at runtime */
Endianness_t detect_endianness(void)
{
    /* Union allows viewing the same 4-byte region as both uint32 and byte array */
    union {
        uint32_t word;
        uint8_t  bytes[4];
    } probe;

    probe.word = 0x01020304U;

    /* On little-endian: bytes[0] = 0x04 (least significant first)
     * On big-endian:    bytes[0] = 0x01 (most significant first) */
    if (probe.bytes[0] == 0x04U) {
        return ENDIAN_LITTLE;
    } else if (probe.bytes[0] == 0x01U) {
        return ENDIAN_BIG;
    }
    return ENDIAN_UNKNOWN;
}

int main(void)
{
    Endianness_t e = detect_endianness();

    printf("Host endianness: %s\n",
           e == ENDIAN_LITTLE ? "Little-Endian (x86/ARM default)" :
           e == ENDIAN_BIG    ? "Big-Endian (SPARC/PowerPC/CCSDS)" :
                                "Unknown");

    /* Visualize how 0xDEADBEEF is stored in memory */
    uint32_t val = 0xDEADBEEFU;
    uint8_t  raw[4];
    memcpy(raw, &val, 4);

    printf("0xDEADBEEF in memory: ");
    for (int i = 0; i < 4; i++) {
        printf("[%d]=0x%02X ", i, raw[i]);
    }
    printf("\n");

    if (e == ENDIAN_LITTLE) {
        printf("Little-endian: LSB (0xEF) is at address 0, MSB (0xDE) at address 3\n");
    } else {
        printf("Big-endian: MSB (0xDE) is at address 0, LSB (0xEF) at address 3\n");
    }

    return 0;
}
Manual byte-swap functions (portable, no POSIX required) 
/* ex3_byteswap.c — compile: gcc -std=c99 -Wall ex3_byteswap.c -o ex3_byteswap */
#include <stdint.h>
#include <stdio.h>

/* Swap bytes of a 16-bit value */
static inline uint16_t bswap16(uint16_t x)
{
    return (uint16_t)(((x & 0x00FFU) << 8) |
                      ((x & 0xFF00U) >> 8));
}

/* Swap bytes of a 32-bit value */
static inline uint32_t bswap32(uint32_t x)
{
    return ((x & 0x000000FFU) << 24) |
           ((x & 0x0000FF00U) <<  8) |
           ((x & 0x00FF0000U) >>  8) |
           ((x & 0xFF000000U) >> 24);
}

/* Convert host uint32_t to big-endian (network byte order).
 * On a big-endian host this is a no-op. */
static inline uint32_t host_to_be32(uint32_t x)
{
    union { uint32_t word; uint8_t bytes[4]; } probe = { .word = 1U };
    /* probe.bytes[0] == 1 means little-endian */
    return (probe.bytes[0] == 1U) ? bswap32(x) : x;
}

static inline uint16_t host_to_be16(uint16_t x)
{
    union { uint16_t word; uint8_t bytes[2]; } probe = { .word = 1U };
    return (probe.bytes[0] == 1U) ? bswap16(x) : x;
}

int main(void)
{
    uint32_t host_val = 0x12345678U;
    uint32_t be_val   = host_to_be32(host_val);

    printf("Host value   : 0x%08X\n", host_val);
    printf("Big-endian   : 0x%08X\n", be_val);

    /* Verify round-trip */
    uint32_t back = host_to_be32(be_val);
    printf("Round-trip   : 0x%08X (should match host)\n", back);

    /* CCSDS APID example: APID 0x18D must go on wire as big-endian */
    uint16_t apid_field = 0x180DU; /* Version+Type+SecHdr bits + APID */
    printf("\nCCSDS field host: 0x%04X  wire: 0x%04X\n",
           apid_field, host_to_be16(apid_field));

    return 0;
}

PHASE 1

Pointers in Depth

Pointer arithmetic, void*, function pointers, const combinations, and the dispatch table pattern used throughout cFS command handling.

Pointer Basics & Arithmetic

A pointer stores the address of another object. Pointer arithmetic respects the pointed-to type: ptr + 1 advances by sizeof(*ptr) bytes. This is why arr[i] and *(arr + i) are identical — array subscripting is defined in terms of pointer arithmetic.

NOTE
Pointer arithmetic is only valid within an array (or one past its last element). Arithmetic on pointers to unrelated objects is undefined behavior — the compiler may generate incorrect code.

void* — Generic Buffers

cFS Software Bus deals with messages of unknown type at the framework layer. The SB layer passes CFE_SB_Buffer_t * (essentially a void *-like opaque pointer) to app-level handlers. void * can receive any pointer without a cast and can be cast to any pointer type, making it the standard way to write type-generic buffer-manipulation code.

Function Pointers & Dispatch Tables

A function pointer stores the address of a function and can call it indirectly. Syntax: return_type (*name)(param_types). cFS command handlers are stored in tables of function pointers — one entry per command function code — so routing a command is an O(1) array lookup rather than a chain of if/else.

TIP
Use a typedef to name the function-pointer type once: typedef void (*CmdHandler_t)(const CFE_SB_Buffer_t *);. This makes table declarations and function signatures far more readable.

A T **pp points to a T *. Common uses: (1) output parameters where the function must set a caller's pointer (e.g., void alloc(int **out)), (2) arrays of strings (char **argv), (3) linked-list manipulation.

/* ex_ptrarith.c — gcc -std=c99 -Wall ex_ptrarith.c */
#include <stdint.h>
#include <stdio.h>

int main(void)
{
    uint32_t buf[5] = {10, 20, 30, 40, 50};
    uint32_t *p = buf;  /* p points to buf[0] */

    printf("=== Array vs Pointer Equivalence ===\n");
    for (int i = 0; i < 5; i++) {
        printf("buf[%d]=%u  *(p+%d)=%u  addr_diff=%td bytes\n",
               i, buf[i],
               i, *(p + i),
               (p + i) - p);  /* ptrdiff_t in elements */
    }

    printf("\n=== Pointer increment ===\n");
    uint32_t *q = buf;
    printf("q before: %p  value: %u\n", (void*)q, *q);
    q++;  /* advances by sizeof(uint32_t) = 4 bytes */
    printf("q after++ : %p  value: %u\n", (void*)q, *q);

    printf("\n=== Byte stepping with uint8_t* ===\n");
    uint8_t *byte_ptr = (uint8_t*)buf;
    printf("First 8 bytes of buf: ");
    for (int i = 0; i < 8; i++) {
        printf("%02X ", byte_ptr[i]);
    }
    printf("\n");

    /* const pointer combinations */
    const uint32_t *cp   = buf;   /* can't modify *cp, CAN re-point cp */
    uint32_t * const fp  = buf;   /* CAN modify *fp, can't re-point fp */

    /* cp = buf + 1;  -- OK */
    /* *cp = 99;      -- compile error */
    /* *fp = 99;      -- OK */
    /* fp = buf + 1;  -- compile error */
    (void)cp; (void)fp;

    return 0;
}
void* generic buffer copy (cFS message buffer pattern) 
/* ex_voidptr.c — gcc -std=c99 -Wall ex_voidptr.c */
#include <stdint.h>
#include <string.h>
#include <stdio.h>
#include <stdbool.h>

#define MAX_MSG_SIZE 128U

/* Simulated cFS-style message buffer — the SB layer is type-agnostic */
typedef struct {
    uint8_t  data[MAX_MSG_SIZE];
    uint32_t length;
} MsgBuffer_t;

/* Generic memcpy wrapper with bounds check — mirrors CFE_PSP_MemCpy */
static bool safe_buf_copy(void *dst, uint32_t dst_size,
                          const void *src, uint32_t copy_len)
{
    if (dst == NULL || src == NULL) {
        printf("ERROR: NULL pointer argument\n");
        return false;
    }
    if (copy_len > dst_size) {
        printf("ERROR: copy_len %u exceeds dst_size %u\n",
               copy_len, dst_size);
        return false;
    }
    memcpy(dst, src, copy_len);
    return true;
}

/* App-level command handler receives a void* (the raw SB buffer).
 * It casts to the known message type — safe only if MsgId matched first. */
typedef struct {
    uint16_t stream_id;   /* CCSDS primary header word 0 */
    uint16_t sequence;    /* CCSDS primary header word 1 */
    uint16_t pkt_len;     /* CCSDS primary header word 2 */
    uint8_t  fc;          /* function code */
    uint8_t  checksum;
    uint32_t param;       /* command parameter */
} MyCmd_t;

static void process_command(const void *buf, uint32_t buf_len)
{
    if (buf_len < sizeof(MyCmd_t)) {
        printf("ERROR: buffer too small (%u < %zu)\n",
               buf_len, sizeof(MyCmd_t));
        return;
    }
    const MyCmd_t *cmd = (const MyCmd_t*)buf;  /* safe cast after length check */
    printf("Command received: FC=0x%02X param=%u\n", cmd->fc, cmd->param);
}

int main(void)
{
    MsgBuffer_t mbuf = {0};

    /* Build a fake command in the buffer */
    MyCmd_t cmd = {
        .stream_id = 0x1880,
        .sequence  = 0xC001,
        .pkt_len   = sizeof(MyCmd_t) - 7,
        .fc        = 0x02,
        .checksum  = 0x00,
        .param     = 42
    };

    safe_buf_copy(mbuf.data, sizeof(mbuf.data), &cmd, sizeof(cmd));
    mbuf.length = sizeof(cmd);

    /* SB passes the buffer as void* — the app casts it */
    process_command(mbuf.data, mbuf.length);

    return 0;
}
Function pointer dispatch table (cFS command routing pattern) 
/* ex_dispatch.c — gcc -std=c99 -Wall ex_dispatch.c */
#include <stdint.h>
#include <stdio.h>
#include <string.h>

/* --- Types --- */
typedef struct {
    uint8_t  data[64];
    uint16_t length;
} SB_Buffer_t;

/* All command handlers have this signature */
typedef void (*CmdHandler_t)(const SB_Buffer_t *buf);

/* Dispatch table entry: handler + expected packet length */
typedef struct {
    CmdHandler_t handler;
    uint16_t     expected_len;
} CmdEntry_t;

/* --- Command function codes --- */
#define CC_NOOP           0U
#define CC_RESET_CTRS     1U
#define CC_SET_PARAM      2U
#define NUM_COMMANDS      3U

/* --- Handler implementations --- */
static void HandleNoop(const SB_Buffer_t *buf)
{
    (void)buf;
    printf("[CMD] NOOP executed — no action taken\n");
}

static void HandleResetCounters(const SB_Buffer_t *buf)
{
    (void)buf;
    printf("[CMD] Counters reset to zero\n");
}

typedef struct {
    uint8_t  hdr[8];
    uint32_t value;
} SetParamCmd_t;

static void HandleSetParam(const SB_Buffer_t *buf)
{
    const SetParamCmd_t *cmd = (const SetParamCmd_t*)buf->data;
    printf("[CMD] SetParam: value=%u\n", cmd->value);
}

/* --- Dispatch table (indexed by function code) --- */
static const CmdEntry_t g_CmdTable[NUM_COMMANDS] = {
    [CC_NOOP]        = { HandleNoop,          8  },
    [CC_RESET_CTRS]  = { HandleResetCounters, 8  },
    [CC_SET_PARAM]   = { HandleSetParam,      sizeof(SetParamCmd_t) },
};

/* --- Dispatcher --- */
static void dispatch_command(uint8_t fc, const SB_Buffer_t *buf)
{
    if (fc >= NUM_COMMANDS) {
        printf("[ERR] Unknown function code: %u\n", fc);
        return;
    }
    if (buf->length != g_CmdTable[fc].expected_len) {
        printf("[ERR] FC=%u length mismatch: got=%u expected=%u\n",
               fc, buf->length, g_CmdTable[fc].expected_len);
        return;
    }
    /* O(1) dispatch — no switch/if chain */
    g_CmdTable[fc].handler(buf);
}

int main(void)
{
    SB_Buffer_t buf = {0};

    buf.length = 8;
    dispatch_command(CC_NOOP, &buf);
    dispatch_command(CC_RESET_CTRS, &buf);

    SetParamCmd_t spcmd = {0};
    spcmd.value = 1234;
    memcpy(buf.data, &spcmd, sizeof(spcmd));
    buf.length = sizeof(spcmd);
    dispatch_command(CC_SET_PARAM, &buf);

    /* Test invalid function code */
    dispatch_command(99, &buf);

    return 0;
}

PHASE 1

Structs, Unions & Memory Layout

Alignment, padding, packed attributes, bit-fields, and unions — the tools for mapping C types directly onto wire protocols.

Struct Layout & Alignment

The compiler aligns each struct member to its natural alignment (typically equal to its size) and may insert padding bytes to satisfy alignment constraints. A char followed by an int often wastes 3 bytes of padding between them.

WARNING
Never use an unmodified C struct to map onto a wire protocol unless it is declared __attribute__((packed)). Compiler padding will silently misalign your fields against the protocol definition.

__attribute__((packed))

GCC and Clang support __attribute__((packed)) on a struct to eliminate all padding. The struct's layout then exactly matches the byte sequence described in the protocol specification. Every CCSDS header struct in cFS uses this attribute. The trade-off is that the compiler may generate slower unaligned-access instructions on some architectures.

Bit-Fields

Within a packed struct, bit-fields let individual members be fewer than 8 bits wide, making it possible to declare the CCSDS Version (3 bits), Type (1 bit), and SecHdr flag (1 bit) as separate named fields in a 16-bit word.

NOTE
Bit-field ordering within a storage unit is implementation-defined. cFS uses bitfields carefully and tests them against known-good byte sequences on each new target.

offsetof & sizeof

offsetof(type, member) from <stddef.h> returns the byte offset of a member within a struct — invaluable for verifying that your packed struct matches the protocol's byte map.

Unions

A union overlays multiple members at the same memory address. The size of the union is the size of its largest member. Unions are commonly used for type-punning (viewing the same bytes as different types) and for telemetry packets with variable payloads.

/* ex_padding.c — gcc -std=c99 -Wall ex_padding.c */
#include <stdint.h>
#include <stddef.h>
#include <stdio.h>

/* BAD: char-int-char causes 6 bytes of padding on 32-bit platforms */
struct BadLayout {
    char     a;      /* 1 byte at offset 0 */
    /* 3 bytes padding to align 'b' to 4 */
    uint32_t b;      /* 4 bytes at offset 4 */
    char     c;      /* 1 byte at offset 8 */
    /* 3 bytes tail padding to align struct size to 4 */
};

/* GOOD: Largest members first — no padding needed */
struct GoodLayout {
    uint32_t b;      /* 4 bytes at offset 0 */
    char     a;      /* 1 byte at offset 4 */
    char     c;      /* 1 byte at offset 5 */
    /* 2 bytes tail padding to align to 4 */
};

/* WIRE: Packed — matches protocol exactly, no padding */
struct __attribute__((packed)) WireLayout {
    uint8_t  a;
    uint32_t b;
    uint8_t  c;
};

int main(void)
{
    printf("=== Struct sizes ===\n");
    printf("BadLayout:  %zu bytes (wastes 6 bytes)\n",
           sizeof(struct BadLayout));
    printf("GoodLayout: %zu bytes (wastes 2 bytes)\n",
           sizeof(struct GoodLayout));
    printf("WireLayout: %zu bytes (no padding)\n",
           sizeof(struct WireLayout));

    printf("\n=== Member offsets of BadLayout ===\n");
    printf("a: %zu  b: %zu  c: %zu\n",
           offsetof(struct BadLayout, a),
           offsetof(struct BadLayout, b),
           offsetof(struct BadLayout, c));

    printf("\n=== Member offsets of WireLayout ===\n");
    printf("a: %zu  b: %zu  c: %zu\n",

}
CCSDS Primary Header — packed struct with bit-fields 
/* ex_ccsds_hdr.c — gcc -std=c99 -Wall ex_ccsds_hdr.c */
#include <stdint.h>
#include <stddef.h>
#include <stdio.h>
#include <string.h>

/*
 * CCSDS Primary Header (CCSDS 133.0-B-2), 6 bytes big-endian:
 *
 *  Word 0 (16-bit): [15:13] Version=0b000  [12] Type(0=TLM,1=CMD)
 *                   [11] SecHdrFlag=1  [10:0] APID
 *  Word 1 (16-bit): [15:14] SeqFlags  [13:0] SeqCount
 *  Word 2 (16-bit): PktDataLen = total_bytes - 7
 */

/* Raw byte representation — safest for cross-platform use */
typedef struct __attribute__((packed)) {
    uint8_t  stream_id_hi;   /* Byte 0: version[7:5] type[4] sec_hdr[3] apid[2:0] */
    uint8_t  stream_id_lo;   /* Byte 1: apid[7:0] */
    uint8_t  sequence_hi;    /* Byte 2: seq_flags[7:6] seq_count[5:0] */
    uint8_t  sequence_lo;    /* Byte 3: seq_count[7:0] */
    uint8_t  pkt_len_hi;     /* Byte 4: pkt_data_len[15:8] */
    uint8_t  pkt_len_lo;     /* Byte 5: pkt_data_len[7:0] */
} CCSDS_PriHdr_t;

/* Helper macros to extract fields (big-endian wire bytes) */
#define CCSDS_GET_TYPE(hdr)     (((hdr).stream_id_hi >> 4) & 0x1U)
#define CCSDS_GET_APID(hdr)     ((uint16_t)(((hdr).stream_id_hi & 0x07U) << 8) | \
                                  (hdr).stream_id_lo)
#define CCSDS_GET_SEQCNT(hdr)   ((uint16_t)(((hdr).sequence_hi & 0x3FU) << 8) | \
                                  (hdr).sequence_lo)
#define CCSDS_GET_PKTLEN(hdr)   ((uint16_t)((hdr).pkt_len_hi << 8) | (hdr).pkt_len_lo)

/* Build a CCSDS telemetry primary header */
static void build_tlm_hdr(CCSDS_PriHdr_t *hdr, uint16_t apid,
                           uint16_t seq_cnt, uint16_t pkt_data_len)
{
    /* Type=0 (TLM), SecHdrFlag=1, Version=0 */
    hdr->stream_id_hi = (uint8_t)(0x08U | ((apid >> 8) & 0x07U));
    hdr->stream_id_lo = (uint8_t)(apid & 0xFFU);
    /* SeqFlags=0b11 (standalone), seq count */

PHASE 2

Deterministic Memory Management

Why flight software never calls malloc after init, and the static allocation patterns that replace it.

The Golden Rule: No malloc After Init

Dynamic heap allocation (malloc/free) is forbidden after system initialization in flight software because:

  • Non-deterministic timing: malloc may take microseconds or milliseconds depending on heap fragmentation. Real-time tasks have hard deadlines measured in microseconds.
  • Heap fragmentation: After thousands of alloc/free cycles, the heap becomes fragmented. A request for 512 bytes may fail even when 10 KB is technically free.
  • No recovery: In space, there is no operator to restart a process that ran out of heap memory. Allocation failure must be impossible at runtime.
IMPORTANT
cFS Executive Services (CFE_ES) provides a memory pool API (CFE_ES_PoolCreate, CFE_ES_GetPoolBuf) built on a fixed static buffer with a deterministic allocator. Even this is used sparingly — most cFS apps use simple static global structs.

Static Allocation Strategies

  • Global/static arrays: static MyMsg_t g_MsgPool[MAX_MSGS] — declared once, lives forever.
  • Stack allocation: Local variables in a function. Be aware of stack size limits on the RTOS.
  • Static local variables: static inside a function — initialized once, persists between calls.

Pool Allocator Pattern

A pool allocator pre-allocates a fixed array of identically-sized objects and maintains a free-list. Allocation is O(1) and deterministic: pop one entry from the free-list. Free is O(1): push back to free-list.

Ring Buffer (Circular Queue)

A ring buffer is the standard structure for telemetry event logging in flight software. It uses two indices (head/tail) into a fixed array. When the buffer is full, the oldest entry is overwritten (or new entries are dropped — policy depends on mission). Access is O(1) with no dynamic allocation.

TIP
Always use memset(ptr, 0, sizeof(*ptr)) to zero-initialize statically allocated objects before use. Uninitialized data is a leading cause of non-deterministic spacecraft anomalies.
Static object pool allocator 
/* ex_pool.c — gcc -std=c99 -Wall ex_pool.c */
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#include <stdio.h>

#define POOL_CAPACITY 8U

/* The object type managed by the pool */
typedef struct {
    uint32_t msg_id;
    uint8_t  data[16];
    bool     in_use;
} MsgObj_t;

/* Pool state — all static, no heap */
static MsgObj_t   g_pool[POOL_CAPACITY];
static uint32_t   g_free_list[POOL_CAPACITY];  /* indices of free slots */
static uint32_t   g_free_top = 0U;             /* stack top */

/* Initialize pool — call once at startup */
void Pool_Init(void)
{
    memset(g_pool, 0, sizeof(g_pool));
    g_free_top = POOL_CAPACITY;
    for (uint32_t i = 0; i < POOL_CAPACITY; i++) {
        g_free_list[i] = i;  /* all slots free */
    }
}

/* Allocate one object — O(1), deterministic */
MsgObj_t *Pool_Alloc(void)
{
    if (g_free_top == 0U) {
        return NULL;  /* pool exhausted */
    }
    uint32_t idx = g_free_list[--g_free_top];
    MsgObj_t *obj = &g_pool[idx];
    memset(obj, 0, sizeof(*obj));  /* always zero-init */
    obj->in_use = true;
    return obj;
}

/* Return object to pool — O(1), deterministic */
bool Pool_Free(MsgObj_t *obj)
{
    if (obj == NULL) return false;

    /* Find the index of this object in the pool array */
    ptrdiff_t idx = obj - g_pool;
    if (idx < 0 || (uint32_t)idx >= POOL_CAPACITY) {
        return false;  /* not our object */
    }
    if (!obj->in_use) {
        return false;  /* double-free guard */
    }

    obj->in_use = false;
    g_free_list[g_free_top++] = (uint32_t)idx;
    return true;
}

int main(void)
{
    Pool_Init();
    printf("Pool capacity: %u\n\n", POOL_CAPACITY);

    MsgObj_t *a = Pool_Alloc();
    MsgObj_t *b = Pool_Alloc();
    MsgObj_t *c = Pool_Alloc();

    if (a) { a->msg_id = 100; printf("Allocated a: msg_id=%u\n", a->msg_id); }
    if (b) { b->msg_id = 200; printf("Allocated b: msg_id=%u\n", b->msg_id); }
    if (c) { c->msg_id = 300; printf("Allocated c: msg_id=%u\n", c->msg_id); }

    printf("Free top: %u (after 3 allocs)\n\n", g_free_top);

    Pool_Free(b);
    printf("Freed b. Free top: %u\n", g_free_top);

    MsgObj_t *d = Pool_Alloc();
    if (d) printf("Re-allocated slot: msg_id=%u (was b's slot)\n\n", d->msg_id);

    /* Exhaust the pool */
    MsgObj_t *extra = NULL;
    while ((extra = Pool_Alloc()) != NULL) { extra->msg_id = 999; }
    printf("Pool exhausted — Pool_Alloc() returned NULL\n");

    return 0;
}
Ring buffer (circular queue) for telemetry events 
/* ex_ringbuf.c — gcc -std=c99 -Wall ex_ringbuf.c */
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#include <stdio.h>

#define RB_CAPACITY 4U  /* power of 2 for efficient modulo */

typedef struct {
    uint32_t event_id;
    char     message[32];
} Event_t;

typedef struct {
    Event_t  buf[RB_CAPACITY];
    uint32_t head;   /* next write position */
    uint32_t tail;   /* next read position */
    uint32_t count;  /* number of items currently in buffer */
} RingBuf_t;

static RingBuf_t g_evtbuf;

void RB_Init(RingBuf_t *rb) {
    memset(rb, 0, sizeof(*rb));
}

bool RB_IsFull(const RingBuf_t *rb)  { return rb->count == RB_CAPACITY; }
bool RB_IsEmpty(const RingBuf_t *rb) { return rb->count == 0U; }

/* Push: overwrites oldest if full (telemetry "overwrite" policy) */
void RB_Push(RingBuf_t *rb, const Event_t *evt)
{
    if (RB_IsFull(rb)) {
        /* Overwrite oldest: advance tail */
        rb->tail = (rb->tail + 1U) % RB_CAPACITY;
        rb->count--;
        printf("  [RB WARN] Buffer full — oldest event dropped\n");
    }
    rb->buf[rb->head] = *evt;
    rb->head = (rb->head + 1U) % RB_CAPACITY;
    rb->count++;
}

bool RB_Pop(RingBuf_t *rb, Event_t *out)
{
    if (RB_IsEmpty(rb)) return false;
    *out = rb->buf[rb->tail];
    rb->tail = (rb->tail + 1U) % RB_CAPACITY;
    rb->count--;
    return true;
}

int main(void)
{
    RB_Init(&g_evtbuf);

    Event_t e;
    for (uint32_t i = 1; i <= 6; i++) {
        e.event_id = i;
        snprintf(e.message, sizeof(e.message), "Event #%u", i);
        printf("Push %u (count before: %u)\n", i, g_evtbuf.count);
        RB_Push(&g_evtbuf, &e);
    }

    printf("\nDraining ring buffer (count=%u):\n", g_evtbuf.count);
    while (RB_Pop(&g_evtbuf, &e)) {
        printf("  ID=%u  msg=\"%s\"\n", e.event_id, e.message);
    }

    return 0;
}

PHASE 2

Defensive Programming & Error Handling

Status code conventions, always-check-return-values discipline, NASA's Power of 10 Rules, and MISRA C key rules.

Status Code Conventions

cFS uses int32_t (aliased CFE_Status_t) as a return type for nearly every API function. Convention: 0 = CFE_SUCCESS, negative values = errors, positive values = warnings/informational. Error codes encode the service (high bits) and specific error (low bits), making them globally unique across all cFS modules.

IMPORTANT
Every function that can fail must have its return value checked. Ignoring a return value in flight software is a critical defect — it is the equivalent of ignoring a fire alarm. Use -Wunused-result to catch this at compile time.

NASA Power of 10 Rules

Gerard Holzmann at JPL formulated 10 rules for safety-critical C code that eliminate the most common sources of embedded software defects:

  1. No complex flow: Restrict to simple control flow — no goto, setjmp, longjmp, or direct/indirect recursion.
  2. Fixed upper bounds on loops: Every loop must have a statically verifiable iteration limit. No unbounded while(1) without a counter guard.
  3. No dynamic memory after init: No malloc/free after initialization. Use static or stack allocation only.
  4. No functions longer than 60 lines: Each function should fit on a single printed page. Long functions hide bugs.
  5. Two or fewer assertions per function: At least 2% of all lines should be assertions. Each assertion checks a condition that must always be true; failure is a programmer error.
  6. Minimum variable scope: Declare variables at the innermost possible scope. Avoid global state except where required.
  7. Check every return value: Every function return value must be checked, or the ignored value must be explicitly cast to (void) to signal intentional discard.
  8. Limit preprocessor use: Use #include and simple #define macros only. No token-pasting, variadic macros, or recursive macro expansion.
  9. Restrict pointer use: No more than one level of pointer dereference per expression. No function pointers (relaxed in cFS for dispatch tables — handled carefully).
  10. Compile warning-free: Code must compile with all warnings enabled (-Wall -Wextra) and zero warnings at the highest warning level, with -Werror.

Key MISRA C:2012 Rules

  • Rule 15.5: A function should have a single point of exit.
  • Rule 17.2: Functions shall not call themselves directly or indirectly (no recursion).
  • Rule 14.2: A for-loop shall be well-formed (init; condition; increment only).
  • Rule 11.3: A cast shall not be performed between a pointer to an object type and a pointer to a different object type.
  • Rule 21.3: The memory allocation functions of <stdlib.h> shall not be used.
  • Rule 16.4: Every switch statement shall have a default clause.
NOTE
NASA JPL applies a strict subset of MISRA C:2012 plus their own Power of 10 rules via automated static analysis (Coverity, Polyspace). Code that violates these rules is blocked from integration.

#include <stdio.h>

/* ----- Error code definitions (mirroring cFS pattern) ----- */
typedef int32_t Status_t;
#define STATUS_SUCCESS       ((Status_t)0)
#define STATUS_ERR_NULL_PTR  ((Status_t)-1)
#define STATUS_ERR_BAD_LEN   ((Status_t)-2)
#define STATUS_ERR_NOT_INIT  ((Status_t)-3)
#define STATUS_ERR_OVERFLOW  ((Status_t)-4)

/* ----- Module state ----- */
typedef struct {
    bool     initialized;
    uint32_t msg_count;
    uint8_t  buffer[256];
    uint32_t buf_len;
} Module_t;

static Module_t g_mod;

/* ----- Functions with proper error propagation ----- */
Status_t Module_Init(void)
{
    memset(&g_mod, 0, sizeof(g_mod));
    g_mod.initialized = true;
    printf("[INIT] Module initialized\n");
    return STATUS_SUCCESS;
}

Status_t Module_WriteData(const uint8_t *data, uint32_t len)
{
    /* Rule: validate inputs before any operation */
    if (data == NULL) {
        printf("[ERR] WriteData: NULL pointer\n");
        return STATUS_ERR_NULL_PTR;
    }
    if (len == 0U || len > 128U) {
        printf("[ERR] WriteData: invalid length %u\n", len);
        return STATUS_ERR_BAD_LEN;
    }
    if (!g_mod.initialized) {
        printf("[ERR] WriteData: module not initialized\n");
        return STATUS_ERR_NOT_INIT;
    }
    if (g_mod.buf_len + len > sizeof(g_mod.buffer)) {
        printf("[ERR] WriteData: buffer overflow (%u + %u > %zu)\n",
               g_mod.buf_len, len, sizeof(g_mod.buffer));
        return STATUS_ERR_OVERFLOW;
    }

    memcpy(&g_mod.buffer[g_mod.buf_len], data, len);
    g_mod.buf_len += len;
    g_mod.msg_count++;
    printf("[OK]  WriteData: wrote %u bytes (total=%u)\n", len, g_mod.buf_len);
    return STATUS_SUCCESS;
}

/* Caller checks every return value */
Status_t Module_RunTask(void)
{
    Status_t status;

    status = Module_Init();
    if (status != STATUS_SUCCESS) {
        printf("[FATAL] Init failed: %d\n", status);
        return status;  /* propagate up */
    }

    uint8_t payload1[] = {0x01, 0x02, 0x03, 0x04};
    status = Module_WriteData(payload1, sizeof(payload1));
    if (status != STATUS_SUCCESS) {
        printf("[WARN] First write failed: %d\n", status);
        /* non-fatal — continue */
    }

    /* Test NULL pointer error */
    status = Module_WriteData(NULL, 4);
    if (status != STATUS_SUCCESS) {
        printf("[CAUGHT] Expected NULL error: %d\n", status);
    }

    /* Test length error */
    status = Module_WriteData(payload1, 0);
    if (status != STATUS_SUCCESS) {
        printf("[CAUGHT] Expected length error: %d\n", status);
    }

    printf("\nFinal: msg_count=%u buf_len=%u\n",
           g_mod.msg_count, g_mod.buf_len);
    return STATUS_SUCCESS;
}

int main(void)
{
    Status_t result = Module_RunTask();
    return (result == STATUS_SUCCESS) ? 0 : 1;
}

PHASE 2

Hardware Modifiers: volatile, const, static

Qualifier keywords that control compiler optimization behavior, storage duration, and linkage — critical for hardware-interfacing flight code.

volatile

The volatile qualifier tells the compiler that a variable's value may change at any time outside normal program flow — e.g., from a hardware register, an interrupt service routine (ISR), or a DMA controller. Without it, the compiler may read the variable once, cache it in a CPU register, and never re-read memory, permanently missing updates.

WARNING
volatile does NOT guarantee atomicity. A volatile uint32_t updated by an ISR can still be read mid-update on architectures where 32-bit writes are not atomic. Use volatile + disable interrupts, or _Atomic (C11), for true race-free access.

Use volatile for:

  • Memory-mapped hardware registers: volatile uint32_t * const UART_DATA = (volatile uint32_t*)0x40001000;
  • Flags shared between an ISR and a task
  • Shared memory regions in multi-processor systems

const

At file scope, const data is placed in the read-only data section (.rodata) by the linker. On embedded targets with ROM, it literally lives in non-writable flash. For function parameters, const T *p signals that the function will not modify the pointed-to data — enforced by the compiler.

static

Two distinct meanings depending on context:

  • At file scope: Internal linkage — the name is not visible outside the translation unit. Every cFS app module uses this to avoid symbol conflicts between apps in the same address space.
  • Inside a function: The variable has static storage duration — it is initialized once and retains its value between calls. Useful for persistent counters and lazily-initialized state.

extern

Declares a variable or function defined in another translation unit. Used to share a single global across multiple .c files. Define in one .c file; declare extern in the shared header.

restrict

(C99) A hint to the compiler that a pointer is the only pointer that will access a memory region during its lifetime. Enables optimizations like vectorization. Used in memcpy(restrict dst, restrict src, n).

NOTE
In cFS, every app wraps all its global state in a single struct (e.g., MY_APP_GlobalData_t g_MyApp_Global). The struct is declared static or kept in the app's own compilation unit, avoiding name collisions between apps loaded in the same process (in the POSIX/Linux simulator).

PHASE 3

Concurrency & Thread Safety

Race conditions, mutexes, semaphores, priority inversion, deadlock, reentrant functions, and C11 atomics.

RTOS Tasks vs POSIX Threads

cFS apps run as RTOS tasks on VxWorks/RTEMS, or as POSIX threads in the Linux simulator. Each task has a priority and a time-slice. The RTOS preempts a lower-priority task whenever a higher-priority task becomes ready. This preemption can happen between any two C statements — even between loading and storing a 32-bit integer on some architectures.

Race Conditions

A race condition occurs when two tasks access shared data concurrently and the final result depends on the timing of their execution. The classic example: two tasks increment a shared counter. If both read the value (5), both add 1, and both write (6), the counter is 6 instead of 7. On a spacecraft that lost track of 1 command out of every million, this is mission-critical.

WARNING
Race conditions in flight software can cause silent data corruption that only manifests during rare timing windows — possibly during the most critical mission phase. Static analysis cannot always detect them. Formal proof or rigorous design discipline is required.

Mutual Exclusion

A mutex (mutual exclusion lock) ensures only one task holds the lock at a time. Other tasks that call lock() block until the lock is released. In OSAL (the OS Abstraction Layer used by cFS): OS_MutSemCreate, OS_MutSemTake, OS_MutSemGive.

Semaphores

  • Binary semaphore: Two states (0/1). Used for signaling — one task gives, another takes (waits). Like a door lock used as a doorbell.
  • Counting semaphore: Counts N available resources. Give increments, Take decrements; blocks at 0.
  • Mutex: A binary semaphore with ownership — only the task that locked it can unlock it, enabling priority inheritance.

Priority Inversion

Priority inversion: a high-priority task (H) waits for a mutex held by a low-priority task (L). A medium-priority task (M) preempts L. H is now blocked behind M — effectively, M runs at higher priority than H. The Mars Pathfinder mission experienced this bug in 1997. Priority inheritance (available in POSIX mutexes with PTHREAD_PRIO_INHERIT) temporarily raises L's priority to H's while L holds the mutex.

Deadlock

Deadlock occurs when four conditions hold simultaneously: (1) mutual exclusion, (2) hold-and-wait, (3) no preemption of locks, (4) circular wait. Prevention: always acquire locks in a globally consistent order (e.g., always lock A before B, never B before A). Alternatively, use try-lock with timeout and back off.

Reentrant Functions

A function is reentrant if it produces correct results when called concurrently from multiple tasks. Requirements: no static/global state modification, no calls to non-reentrant library functions. Use only local variables or parameters.

C11 _Atomic

C11 provides <stdatomic.h> with atomic types (atomic_int, atomic_uint32_t) and operations (atomic_load, atomic_store, atomic_fetch_add) that guarantee atomicity without mutexes for simple scalar updates.

#include <stdint.h>
#include <stdio.h>
#include <pthread.h>

#define NUM_THREADS  4
#define INCREMENTS   100000

/* ---- UNSAFE counter (race condition) ---- */
static volatile uint32_t g_unsafe_counter = 0U;

static void *unsafe_thread(void *arg)
{
    (void)arg;
    for (int i = 0; i < INCREMENTS; i++) {
        g_unsafe_counter++;  /* NOT atomic: read-modify-write race */
    }
    return NULL;
}

/* ---- SAFE counter (mutex protected) ---- */
static uint32_t         g_safe_counter = 0U;
static pthread_mutex_t  g_mutex        = PTHREAD_MUTEX_INITIALIZER;

static void *safe_thread(void *arg)
{
    (void)arg;
    for (int i = 0; i < INCREMENTS; i++) {
        pthread_mutex_lock(&g_mutex);
        g_safe_counter++;   /* protected: no race */
        pthread_mutex_unlock(&g_mutex);
    }
    return NULL;
}

/* ex_reentrant.c — gcc -std=c99 -Wall ex_reentrant.c */
#include <stdint.h>
#include <stdio.h>
#include <string.h>

/* ---- NON-REENTRANT: static buffer shared across all callers ---- */
static char g_convert_buf[32];  /* single shared buffer — BAD! */

const char *nonreentrant_hex(uint32_t val)
{
    /* If two tasks call this simultaneously, they both write g_convert_buf.
     * The first caller's result is destroyed before it can use it. */
    snprintf(g_convert_buf, sizeof(g_convert_buf), "0x%08X", val);
    return g_convert_buf;  /* pointer into static buffer */
}

/* ---- REENTRANT: caller provides buffer — each call has its own ---- */
char *reentrant_hex(uint32_t val, char *buf, size_t bufsz)
{
    /* Only uses parameters and local variables — fully reentrant */
    snprintf(buf, bufsz, "0x%08X", val);
    return buf;
}

/* ---- Non-reentrant problem demo ---- */
static void demo_nonreentrant(void)
{
    /* Simulate two tasks calling in quick succession */
    const char *p1 = nonreentrant_hex(0xDEADBEEF);
    /* If task 2 preempts here and calls nonreentrant_hex(0xCAFEBABE),
     * p1 now points to "0xCAFEBABE" -- task 1 prints wrong value! */
    const char *p2 = nonreentrant_hex(0xCAFEBABE);

}

{

    const char *p2 = reentrant_hex(0xCAFEBABE, buf2, sizeof(buf2));
    printf("p1=%s  p2=%s  (both correct)\n", p1, p2);
}

PHASE 3

Inter-Task Communication (IPC)

POSIX message queues, OSAL queue APIs, producer-consumer pattern, and how cFS Software Bus abstracts all of this.

The cFS Software Bus as the Primary IPC

In cFS, the Software Bus (SB) is the primary IPC mechanism. Apps publish messages to the bus without knowing which other apps subscribe. This decouples apps — you can add, remove, or replace an app without modifying senders. Under the hood, the SB uses OS message queues (OSAL queues) and copies messages into subscriber pipes.

POSIX Message Queues

POSIX MQs (<mqueue.h>) provide kernel-managed FIFO queues of fixed maximum message size. Key operations:

  • mq_open(name, flags, mode, attr) — create/open a named queue
  • mq_send(mqd, msg, len, priority) — enqueue a message
  • mq_receive(mqd, buf, len, priority) — dequeue (blocks if empty)
  • mq_timedreceive — dequeue with timeout (preferred in flight SW)
  • mq_close / mq_unlink — cleanup

OSAL Queue API

OSAL wraps OS-specific queues with a portable API: OS_QueueCreate, OS_QueuePut, OS_QueueGet. cFS SB pipes are built on OSAL queues internally.

TIP
Always use mq_timedreceive (or OSAL's timeout equivalent) rather than blocking forever. Flight software tasks must be able to wake up periodically to perform housekeeping, check watchdog timers, and remain responsive to commands even when no data is flowing.

Producer-Consumer Pattern

One or more producers generate data and enqueue it. One or more consumers dequeue and process it. The queue acts as a buffer that decouples their rates. In cFS: sensor apps produce telemetry packets (publish to SB), and the telemetry output app consumes and downlinks them.

NOTE
Non-blocking send (O_NONBLOCK or OS_CHECK in OSAL) returns immediately with an error if the queue is full. Blocking with timeout (OS_PEND) waits up to a deadline. Choose based on whether a full queue is a mission-critical error or a recoverable condition.

/* ex_mqueue.c — gcc -std=c99 -Wall -pthread ex_mqueue.c -lrt */
#include <stdint.h>
#include <stdio.h>
#include <string.h>
#include <mqueue.h>
#include <pthread.h>
#include <time.h>
#include <fcntl.h>
#include <errno.h>

#define QUEUE_NAME  "/cfs_ipc_demo"
#define MSG_SIZE    32U
#define QUEUE_DEPTH 8U
#define NUM_MSGS    5

typedef struct {
    uint32_t msg_id;
    char     text[28];
} Msg_t;

static void *producer_thread(void *arg)
{
    (void)arg;
    mqd_t mq = mq_open(QUEUE_NAME, O_WRONLY);
    if (mq == (mqd_t)-1) { perror("mq_open producer"); return NULL; }

    for (int i = 0; i < NUM_MSGS; i++) {
        Msg_t m;
        m.msg_id = (uint32_t)i;
        snprintf(m.text, sizeof(m.text), "TLM packet #%d", i);
        if (mq_send(mq, (const char*)&m, sizeof(m), 0) == -1) {
            perror("mq_send");
        } else {
            printf("[PROD] Sent: id=%u text=\"%s\"\n", m.msg_id, m.text);
        }
    }
    mq_close(mq);
    return NULL;
}

static void *consumer_thread(void *arg)
{
    (void)arg;
    mqd_t mq = mq_open(QUEUE_NAME, O_RDONLY);
    if (mq == (mqd_t)-1) { perror("mq_open consumer"); return NULL; }

    struct timespec ts;
    for (int i = 0; i < NUM_MSGS; i++) {
        Msg_t m;
        /* Use timed receive — don't block forever */
        clock_gettime(CLOCK_REALTIME, &ts);
        ts.tv_sec += 2;  /* 2-second timeout */
        ssize_t n = mq_timedreceive(mq, (char*)&m, sizeof(m), NULL, &ts);
        if (n == -1) {
            perror("mq_timedreceive");
        } else {
            printf("[CONS] Recv: id=%u text=\"%s\"\n", m.msg_id, m.text);
        }
    }
    mq_close(mq);
    return NULL;
}

int main(void)
{
    struct mq_attr attr = {
        .mq_flags   = 0,
        .mq_maxmsg  = QUEUE_DEPTH,
        .mq_msgsize = sizeof(Msg_t),
        .mq_curmsgs = 0
    };

    mq_unlink(QUEUE_NAME);  /* clean up from previous run */
    mqd_t mq = mq_open(QUEUE_NAME, O_CREAT | O_RDWR, 0600, &attr);
    if (mq == (mqd_t)-1) { perror("mq_open create"); return 1; }
    mq_close(mq);

    pthread_t prod, cons;
    pthread_create(&cons, NULL, consumer_thread, NULL);
    pthread_create(&prod, NULL, producer_thread, NULL);
    pthread_join(prod, NULL);
    pthread_join(cons, NULL);

    mq_unlink(QUEUE_NAME);
    return 0;
}

#define MAX_Q_DEPTH 8

static uint32_t g_q_head = 0, g_q_tail = 0, g_q_count = 0;

OS_Status OS_QueueCreate(osal_id_t *qid, const char *name,
                         osal_blockcount_t depth, size_t data_size,
                         uint32_t flags)

    *qid = 3001;
    g_q_head = g_q_tail = g_q_count = 0;

           name, *qid, MAX_Q_DEPTH, (size_t)MSG_SZ);

OS_Status OS_QueuePut(osal_id_t qid, const void *data,
                      size_t size, uint32_t flags)
{
    (void)qid; (void)flags;
    if (g_q_count >= MAX_Q_DEPTH) return OS_ERR_FULL;
    size_t copy_sz = size < MSG_SZ ? size : MSG_SZ;
    memcpy(g_q_store[g_q_head], data, copy_sz);
    g_q_head = (g_q_head + 1) % MAX_Q_DEPTH;
    g_q_count++;
    return OS_SUCCESS;
}

OS_Status OS_QueueGet(osal_id_t qid, void *data, size_t size,
                      size_t *copied, int32_t timeout)
{
    (void)qid; (void)timeout;
    if (g_q_count == 0) return OS_ERR_EMPTY;
    size_t copy_sz = size < MSG_SZ ? size : MSG_SZ;
    memcpy(data, g_q_store[g_q_tail], copy_sz);
    g_q_tail = (g_q_tail + 1) % MAX_Q_DEPTH;
    g_q_count--;
    if (copied) *copied = copy_sz;
    return OS_SUCCESS;
}

        AppMsg_t msg = { .id = i };
        snprintf(msg.text, sizeof(msg.text), "pkt_%u", i);
        status = OS_QueuePut(qid, &msg, sizeof(msg), OS_CHECK);
        printf("[PUT] id=%u status=%d\n", msg.id, status);
    }

    /* Consumer drains */
    AppMsg_t rxmsg;
    size_t   rxsz;
    while (OS_QueueGet(qid, &rxmsg, sizeof(rxmsg), &rxsz, OS_CHECK)
           == OS_SUCCESS) {
        printf("[GET] id=%u text=\"%s\" copied=%zu\n",
               rxmsg.id, rxmsg.text, rxsz);
    }

    /* Try to get from empty queue */
    status = OS_QueueGet(qid, &rxmsg, sizeof(rxmsg), &rxsz, OS_CHECK);
    printf("[GET] Empty queue status=%d (expected %d)\n",
           status, OS_ERR_EMPTY);

    return 0;
}

Timers & Clocks

POSIX high-resolution timers, monotonic clocks, and periodic scheduling patterns for flight software.

POSIX High-Resolution Timers (timer_create)

Beyond setitimer(), the modern POSIX API uses timer_create(), timer_settime(), and timer_gettime() for flexible timer management. Timers can be set to expire once (one-shot) or repeatedly (periodic), and they deliver signals with sigevent notification.

IMPORTANT
In flight software, use CLOCK_MONOTONIC as the clock ID for all timers. This ensures timing measurements are not affected by system clock adjustments.

The following example demonstrates how to create a one-shot POSIX timer using timer_create() that fires after a specified duration and executes a signal handler:

/* ex5_hrtimer.c — gcc -std=c99 -Wall ex5_hrtimer.c -lrt */
#include <stdio.h>
#include <signal.h>
#include <time.h>
#include <unistd.h>

static void handler(int sig, siginfo_t *si, void *uc)
{
    printf("Timer expired! Overrun count: %d\n", si->si_overrun);
}

int main(void)
{
    struct sigaction sa;
    struct sigevent se;
    timer_t timer;

    /* Install signal handler */
    memset(&sa, 0, sizeof(sa));
    sa.sa_sigaction = handler;
    sa.sa_flags = SA_SIGINFO;
    sigaction(SIGRTMIN, &sa, NULL);

    /* Configure the sigevent structure */
    se.sigev_notify = SIG_SIGTHREAD;
    se.sigev_signo = SIGRTMIN;
    se.sigev_value.sival_int = 0;

    /* Create the timer */
    if (timer_create(CLOCK_MONOTONIC, &se, &timer) == -1) {
        perror("timer_create");
        return 1;
    }

    /* Set the timer to expire after 2 seconds, one-shot */
    struct itimerspec its;
    its.it_value.tv_sec  = 2;
    its.it_value.tv_nsec = 0;
    its.it_interval.tv_sec  = 0;
    its.it_interval.tv_nsec = 0;

    if (timer_settime(timer, 0, &its, NULL) == -1) {
        perror("timer_settime");
        return 1;
    }

    /* Block until the timer expires */
    (void)getchar();

    /* Delete the timer */
    if (timer_delete(timer) == -1) {
        perror("timer_delete");
    }

    return 0;
}

Software Bus (CFE_SB)

Publish-subscribe message routing for spacecraft communication.

Publish-Subscribe Pattern

The cFS Software Bus (CFE_SB) implements a publish-subscribe messaging pattern. Publishers send messages to a topic ID without knowing who subscribes. Subscribers express interest in a message ID and receive all published messages matching that ID. This decouples producers from consumers — you can add, remove, or replace apps without modifying senders.

IMPORTANT
Messages are buffered in pipes. A subscriber creates a pipe with CFE_SB_CreatePipe and subscribes to desired message IDs with CFE_SB_Subscribe. The SB routes matching publications to the appropriate pipe.

Message Publication

To publish a message, an app builds a data structure, fills in the fields, and calls CFE_SB_Publish with the message reference and the topic ID. The topic ID is a 16-bit value that identifies the message type. Multiple subscribers can receive the same message simultaneously.

Pipe Creation

Each subscriber creates a receive pipe using CFE_SB_CreatePipe. The pipe has a maximum depth and message size. When the pipe is full, new messages either overwrite the oldest (default policy) or are dropped, depending on the pipe configuration.

TIP
Use descriptive topic IDs (e.g., TELEMETRY_HK_T) rather than raw numbers. Define them in a header file shared between publisher and subscriber apps.

App Structure & Lifecycle

How cFE apps are structured from entry point to periodic task to clean exit.

cFE App Entry Points

Every cFE application must provide three essential entry points that the cFE executive calls during its lifecycle:

  1. int32_t AppMain() — the primary task function. This is where the app spends most of its time, typically waiting for messages, performing housekeeping, or processing data.
  2. int32_t AppInit() — called once during system bootstrap. Use this for one-time setup: creating pipes, registering task priorities, allocating static buffers.
  3. void AppHealthCheck() — called periodically by the cFE watchdog. This is the app's chance to report status, freshness of data, or check its own internal health.
IMPORTANT
The cFE executive calls these functions — you do not call them directly. The function signatures must match exactly what the cFE expects, or the linker will fail.

Housekeeping Pattern

Every cFE app implements a housekeeping function that runs periodically. Typical housekeeping duties include:

  • Reporting health status via CFE_EVS_SendEvent
  • Refreshing timestamps on housekeeping telemetry
  • Checking for watchdog timeouts
  • Performing any necessary cleanup or reinitialization

Termination and Exit

When a cFE app needs to terminate, it calls CFE_ES_Exit(status). The executive performs cleanup: closing pipes, freeing resources, and signaling the parent process. An app should never simply return from AppMain — always use the explicit exit function.

Command Dispatch Tables

Routing function codes to handlers — the cFS command pattern.

cFS Command Framework

The cFS command framework provides a standardized way to receive and route command packets from the ground system. Commands are sent as CCSDS telecommand packets with a function code (FC) in the primary header. The receiving app routes the command to the appropriate handler based on the FC.

IMPORTANT
Every command handler must have the signature: void (*handler)(const CFE_SB_Buffer_t *). The dispatch table maps function codes to handlers, enabling O(1) lookup without a switch statement.

Function Code Convention

Function codes are typically numbered 0-N. FC 0 is usually reserved for NOOP (no-operation). Other common conventions:

  • FC 1: Reset counters
  • FC 2: Set parameters
  • FC 3-255: Application-specific commands

Dispatch Table Pattern

A dispatch table is an array of structures, each containing a handler function pointer and the expected packet length. The dispatcher checks the function code range, verifies the packet length, and then calls the handler — all in O(1) time.

TIP
Use a typedef for the handler type: typedef void (*CmdHandler_t)(const CFE_SB_Buffer_t *). This makes table declarations far more readable.
Command dispatch table pattern 
/* ex_cmd_dispatch.c — gcc -std=c99 -Wall ex_cmd_dispatch.c */
#include <stdint.h>
#include <stdio.h>
#include <string.h>

#define CMD_NOOP             0U
#define CMD_RESET          1U
#define CMD_SET_PARAM      2U
#define NUM_COMMANDS       3U

/* Handler type definition */
typedef void (*CmdHandler_t)(const void *buf);

/* Command handler implementations */
static void HandleNoop(const void *buf)
{
    (void)buf;
    printf("[CMD] NOOP executed\n");
}

static void HandleResetCounters(const void *buf)
{
    (void)buf;
    printf("[CMD] Counters reset\n");
}

static void HandleSetParam(const void *buf)
{
    const int32_t *param = (const int32_t *)buf;
    printf("[CMD] Set parameter: %d\n", *param);
}

/* Dispatch table: indexed by function code */
static const CmdEntry_t g_CmdTable[NUM_COMMANDS] = {
    [CMD_NOOP]        = { HandleNoop,          8  },
    [CMD_RESET]       = { HandleResetCounters, 8  },
    [CMD_SET_PARAM]   = { HandleSetParam,      sizeof(int32_t) },
};

/* Dispatcher function */
static void DispatchCommand(uint8_t fc, const void *buf)
{
    if (fc >= NUM_COMMANDS) {
        printf("[ERR] Unknown function code: %u\n", fc);
        return;
    }
    if (((const uint8_t *)buf)[0] != 0x1880U) {
        printf("[ERR] Invalid packet header\n");
        return;
    }
    if (buf_expected_len != g_CmdTable[fc].expected_len) {
        printf("[ERR] Length mismatch: got %u expected %u\n",
               ((const uint8_t *)buf)[1], g_CmdTable[fc].expected_len);
        return;
    }
    /* O(1) dispatch — no switch/if chain */
    g_CmdTable[fc].handler(buf);
}

int main(void)
{
    /* Test all commands */
    DispatchCommand(CMD_NOOP, NULL);
    DispatchCommand(CMD_RESET, NULL);
    DispatchCommand(CMD_SET_PARAM, (const void *)&(int32_t){42});
    /* Test invalid FC */
    DispatchCommand(99, NULL);
    return 0;
}

CCSDS Packets in C

Building CCSDS telemetry and telecommand packets that match the wire protocol.

CCSDS Primary Header

The CCSDS primary header is 6 bytes big-endian and contains the version, type, secondary header flag, and APID. Every cFS packet begins with this header. The protocol mandates big-endian byte order for all multi-byte fields.

IMPORTANT
Without __attribute__((packed)), compiler padding will add bytes between fields, causing the packet to not match the wire specification. Always use __attribute__((packed)) on your packet struct.

Secondary Header (Optional)

If the type field indicates a secondary header is present, an additional 2 bytes follow the primary header. The secondary header contains version numbers and sequence flags specific to the mission.

Telemetry Packet Body

The payload following the header contains mission-specific data. The structure must use __attribute__((packed)) and bit-fields where appropriate to exactly match the protocol definition.

Telecommand Packet

Telecommands follow the same primary header format but may include additional secondary header fields and a parameter field. The function code (FC) is located in the primary header at a fixed bit position.

TIP
Use the helper macros from the p1t3 section to extract fields: CCSDS_GET_TYPE, CCSDS_GET_APID, CCSDS_GET_SEQCNT, CCSDS_GET_PKTLEN.
CCSDS telemetry packet builder 
/* ex_ccsds_tlm.c — gcc -std=c99 -Wall ex_ccsds_tlm.c */
#include <stdint.h>
#include <stdio.h>
#include <string.h>

/* Packed struct for CCSDS telemetry packet */
typedef struct __attribute__((packed)) {
    uint8_t  stream_id_hi;   /* Byte 0: version[7:5] type[4] sec_hdr[3] apid[2:0] */
    uint8_t  stream_id_lo;   /* Byte 1: apid[7:0] */
    uint8_t  sequence_hi;    /* Byte 2: seq_flags[7:6] seq_count[5:0] */
    uint8_t  sequence_lo;    /* Byte 3: seq_count[7:0] */
    uint8_t  pkt_len_hi;     /* Byte 4: pkt_data_len[15:8] */
    uint8_t  pkt_len_lo;     /* Byte 5: pkt_data_len[7:0] */
    int16_t  temperature;
    uint8_t  status_flag;
    uint8_t  science_data[3];
} CcsdsTlmPacket_t;

/* Build a CCSDS telemetry packet */
static void build_packet(CcsdsTlmPacket_t *pkt, uint16_t apid, uint16_t seq,
                         int16_t temp, uint8_t flags, uint8_t *science)
{
    /* Type=0 (TLM), SecHdrFlag=0, Version=0, APID */
    pkt->stream_id_hi = (uint8_t)((apid >> 8) & 0x07U);
    pkt->stream_id_lo = (uint8_t)(apid & 0xFFU);
    /* SeqFlags=0b00 (no sec hdr), seq count */
    pkt->sequence_hi  = (uint8_t)((seq >> 8) & 0x3FU);
    pkt->sequence_lo  = (uint8_t)(seq & 0xFFU);
    /* Packet data length = 2 + 3 = 5 bytes (temp + flags + science[3]) */
    uint16_t data_len = 2 + 3;
    pkt->pkt_len_hi   = (uint8_t)((data_len >> 8) & 0xFFU);
    pkt->pkt_len_lo   = (uint8_t)(data_len & 0xFFU);
    pkt->temperature  = temp;
    pkt->status_flag  = flags;

PHASE 5

Static & Dynamic Analysis

Using compiler tools to find bugs before they fly.

Static Analysis with PC-lint / Astrée

Static analysis tools examine source code without executing it, searching for patterns that indicate bugs, security vulnerabilities, or safety violations. For flight software, tools like PC-lint, Astrée, or the GCC plug-in are commonly used. These tools can detect issues like uninitialized variables, out-of-bounds access, and division by zero at compile time.

IMPORTANT
Run static analysis as part of every build cycle. Many cFE bugs are caught early by PC-lint's aircraft rule sets, which encode decades of flight software safety guidelines.

Dynamic Analysis & Sanitizers

Dynamic analysis tools execute the code with instrumentation to detect runtime issues. GCC and Clang provide sanitizers for address sanitization (-fsanitize=address), undefined behavior (-fsanitize=undefined), and memory leak detection (-fsanitize=leak). While these are primarily for development, they complement static analysis.

TIP
Use -Wall -Wextra as a minimum, and enable cFE-specific warning flags via the provided toolchain.
GCC sanitizer build flags 
# Enable sanitizers in CMake
set(CMAKE_C_FLAGS "${CMAKE_C_FLAGS} -fsanitize=address -fsanitize=undefined")
set(CMAKE_EXE_LINKER_FLAGS "${CMAKE_EXE_LINKER_FLAGS} -fsanitize=address")

PHASE 5

Unit Testing with UT-Assert

Framework for testing cFE applications with assertion checking.

UT-Assert Framework

The UT-Assert (Unit Testing with Assertions) framework is the standard unit testing utility for cFS flight software. It provides UT_ASSERT, UT_CHECK, and UT_ASSERT_EQUAL macros that report failing conditions with file, line, and a descriptive message. Tests are organized into test groups and can be run via the command-line tester tool.

IMPORTANT
Never use the standard C assert() in cFE code — it is disabled in production builds. Always use UT_ASSERT from the UT-Assert framework, which works in both development and flight configurations.

Test Pattern

UT-Assert unit test pattern 
/* test_example.c — linked with ut_assert library */
#include <ut_assert.h>
#include <stdio.h>

void test_division(void){
    int32_t result;
    UT_ASSERT_divide(10, 2, &result);
    UT_ASSERT_EQUAL(result, 5);
}

int main(void){
    int num_failures = 0;
    num_failures += UT_RUN(test_division);
    if (num_failures == 0) {
        printf("All tests passed!\n");
    }
    return num_failures;
}
